01 / Install

Set it up once. Use it anytime.

In the Claude app, on the web or desktop

  1. Download the skill. Keep it as a .zip file. You do not need to open it.
  2. In Claude, open Settings and check that Code execution and file creation is turned on. On a Team or Enterprise plan, your admin controls this.
  3. Go to Customize, then Skills. Click +, choose Create skill, then Upload a skill, and pick the zip.
  4. Turn the skill on.
  5. Start a new chat and type:
Start my operating map.

On a Mac, did the download turn into a folder? Right-click the folder, choose Compress, and upload the new .zip. Menu names in Claude change from time to time. If yours look different, see Claude's help page on skills.

In Claude Code

  1. Download the skill, then run this in the folder where you saved it:
mkdir -p ~/.claude/skills && unzip travel-operating-map.zip -d ~/.claude/skills
  1. Type /travel-operating-map, or just say "Start my operating map."

No Skills option? Use the one-file guide.

  1. Download the guide. It is the same skill in one file.
  2. Start a new chat or Project in Claude and attach the file.
  3. Type:
Follow this guide and start my operating map.

02 / Try it

Three ways to start.

Type any of these in a new chat once the skill is on.

Start my operating map.
Give me a quick operating map snapshot.
Help me write escalation rules for my VA.

Leave out client names, passport numbers, and card details. Describe the work, not the people. If you stop halfway, Claude gives you the map so far. Next time, attach it and say "pick up where I left off."
